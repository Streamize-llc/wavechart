# wavechart — archived

> **⚠️ This project is archived and no longer maintained.**
>
> It was the purpose-built Canvas2D renderer for an earlier Pine visualization
> pipeline. That role is now served by the open pair:
>
> - **[resin](https://github.com/nullarch/resin)** — Pine Script v5/v6 compiler
>   and runtime for JavaScript, which captures the full visualization data
> - **[resin-lightweight-charts](https://github.com/nullarch/resin-lightweight-charts)**
>   — renders that data on TradingView's open-source lightweight-charts
>
> The code remains browsable under the MIT license; the rendering primitives
> (per-bar background stripes, Pine shape glyphs, table overlays) may be useful
> as reference for lightweight-charts custom primitives.
